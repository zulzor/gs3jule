# Инструкции по Сборке и Запуску Проекта

Это Flutter-проект, созданный для управления спортивной школой.

## 1. Предварительные требования

Убедитесь, что у вас установлен **Flutter SDK**. Инструкции по установке можно найти на [официальном сайте Flutter](https://flutter.dev/docs/get-started/install).

## 2. Установка Зависимостей

Перед запуском проекта необходимо добавить недостающие зависимости.

1.  Откройте файл `pubspec.yaml` в корне проекта.
2.  Добавьте следующую строку в раздел `dependencies`:

    ```yaml
    dependencies:
      flutter:
        sdk: flutter
      # ...другие зависимости
      table_calendar: ^3.1.0 # Используйте последнюю версию
    ```

3.  Сохраните файл и выполните в терминале команду для установки зависимостей:

    ```bash
    flutter pub get
    ```

## 3. Включение Календаря

В файле `lib/screens/manager/training_calendar_screen.dart` используется заглушка для календаря, чтобы избежать ошибок компиляции. Чтобы включить настоящий календарь:

1.  Раскомментируйте импорт `table_calendar`:
    ```dart
    import 'package:table_calendar/table_calendar.dart';
    ```
2.  Замените виджет-заглушку (`GestureDetector` с `Container`) на настоящий `TableCalendar`. Вы можете найти закомментированный код с `TableCalendar` в истории изменений этого файла или реализовать его заново, используя документацию пакета.

## 4. Запуск Приложения

### Для веб-версии:
```bash
flutter run -d chrome
```

### Для Android-эмулятора или устройства:
```bash
flutter run
```

## 5. Сборка Финальных Файлов

### Сборка веб-версии:
Выполните команду:
```bash
flutter build web
```
Файлы для развертывания будут находиться в директории `build/web`.

### Сборка APK для Android:
Выполните команду:
```bash
flutter build apk
```
Файл `.apk` будет находиться в директории `build/app/outputs/flutter-apk/`. Его можно установить на любое Android-устройство.
